## 1. プロジェクト概要

### 1.1 目的

ギター演奏者が練習中のリファレンスとして使用できる Web アプリ。キー・スケール・コードを指板上で視覚的に確認し、自分のコード進行やフレーズを保存・共有できる環境を提供する。

### 1.2 ターゲットユーザー

- ギター中級者（コードや音楽理論の基礎知識がある）
- 曲のキー・スケールを意識して練習したい人
- 耳コピや作曲でコード進行を記録・参照したい人

### 1.3 利用シーン

- **練習中のリファレンス**: PCの画面に表示しながら演奏・練習する

### 1.4 対象デバイス方針

**デスクトップファースト**で開発する。練習中はPCをそばに置いて参照する利用形態を主とし、大きな指板表示を最優先とする。モバイル・タブレット対応はPhase 2以降で検討する（NF-01参照）。

## 2. 機能要件

### 2.1 キー・スケール機能

| # | 機能 | 説明 |
|---|------|------|
| F-01 | キー判別 | 入力したコード群からキー（調）を推定して表示 |
| F-02 | スケール選択 | 対応スケール一覧から選択可能（対応スケールは §2.4 参照） |
| F-03 | スケール構成音表示 | 選択したキー＋スケールの構成音（音名）を一覧表示 |
| F-04 | ダイアトニックコード表示 | キーに対応するダイアトニックコード（I〜VII）を表示 |

### 2.2 指板表示機能

| # | 機能 | 説明 |
|---|------|------|
| F-05 | 指板ビジュアライザー | 画面上段にフル幅で大きく表示（12フレット幅、SVG描画） |
| F-06 | スケール構成音の指板表示 | 選択したスケールの構成音を指板上にハイライト |
| F-08 | フレット範囲変更 | 表示開始フレットをスライダーで変更可能（0〜12） |
| F-09 | ルート音ハイライト | ルート音をオレンジ、その他の構成音をグリーンで色分け表示。凡例を併記 |
| F-16 | 開放弦インジケーター | 開始フレットが0のとき、構成音に該当する開放弦をナット左側に輪で表示 |
| F-17 | ポジションマーク表示 | 実際のギターと同様のインレイ（3,5,7,9F: シングル / 12,24F: ダブル）を表示 |
| F-18 | 音名ラベル表示 | 各ドット内に音名を表示（色だけに依存しない、NF-04対応） |

> **Note 1**: コードフォーム表示（旧 F-07）は削除。スケール上での構成音確認に集中する。  
> **Note 2**: v1.1の「5フレット幅のコンパクト表示」は、UIモック検証の結果**12フレット幅の大型表示**に変更（デスクトップファースト方針による）。

### 2.3 コード進行・フレーズ保存機能

| # | 機能 | 説明 |
|---|------|------|
| F-10 | コード進行入力 | コード名をシーケンシャルに入力してコード進行を作成 |
| F-11 | フレーズ入力 | 任意のフレーズ名・メモ・コードリストをセットで登録 |
| F-12 | 保存・一覧表示 | 作成したコード進行・フレーズをローカル or クラウドに保存し一覧表示 |
| F-13 | 指板プレビュー | 保存したコード進行の各コードを指板上で順番に確認 |
| F-14 | 共有 URL 生成 | 保存データをリンク共有できる URL を発行 |
| F-15 | メモ追加 | 各コード進行・フレーズにテキストメモを付与 |

### 2.4 対応スケール一覧

#### Phase 1（MVP）

| スケール | 説明 |
|---------|------|
| Major（Ionian） | 長調の基本スケール |
| Natural Minor（Aeolian） | 短調の基本スケール |
| Major Pentatonic | メジャーペンタトニック |
| Minor Pentatonic | マイナーペンタトニック |
| Blues Scale | マイナーペンタトニック + ♭5（ブルーノート）|

#### Phase 2 以降（拡張予定）

| スケール | 説明 |
|---------|------|
| Dorian | 第2旋法（マイナー系モード） |
| Mixolydian | 第5旋法（メジャー系モード） |
| Harmonic Minor | 和声的短音階 |
| Melodic Minor | 旋律的短音階 |
| その他モーダルスケール | 需要に応じて追加 |

## 3. 非機能要件

| # | 項目 | 要件 |
|---|------|------|
| NF-01 | デバイス対応 | デスクトップファースト（Phase 1）。モバイル・タブレットのレスポンシブ対応はPhase 2以降で検討 |
| NF-02 | オフライン対応 | 基本機能（指板表示・スケール確認）はオフラインでも動作 |
| NF-03 | パフォーマンス | 指板の再描画は 100ms 以内 |
| NF-04 | アクセシビリティ | 音名表示は色だけでなくラベルでも識別可能 |

## 4. 画面構成（ページ設計）

```
/                    ← ホーム（キー・スケール選択 + 指板表示）
/progressions        ← コード進行・フレーズ一覧
/progressions/new    ← コード進行・フレーズ作成
/progressions/:id    ← 詳細表示・編集・共有
```

> **Note**: `/chords`（コード辞書）は F-07 削除に伴い不要となったため除外。

### 4.1 共通レイアウト

- **開閉式サイドバー**（左固定）: 全画面共通のナビゲーション。閉じるとアイコンのみの幅になり、指板表示領域が広がる
- **メインエリア**: 1画面に収まるレイアウトを基本とし、縦スクロールを極力発生させない

### 4.2 画面別レイアウト（UIモック確定版）

| 画面 | 構成 |
|------|------|
| ホーム | 上段: 指板（フル幅）/ 下段左: 選択エリア（キーピル + スケール選択）/ 下段右: 理論情報エリア（構成音 + ダイアトニックコード） |
| 一覧 | 検索バー + フィルタータブ（1行）/ カードグリッド（3列、タイプ別アクセントカラー: コード進行=青・紫、フレーズ=アンバー） |
| 新規作成 | 左: 入力フォーム（タイプ・タイトル・キー/スケール・コードトークン・メモ）/ 右: 指板プレビュー + コードステッパー |
| 詳細 | 上段: 指板（フル幅）/ 下段左: メタ情報（キー・メモ・共有リンク）/ 下段右: コードステッパー（クリックで指板に構成音表示） |

> **参照**: UIモックアップ `guitar-app-mockup/`（index.html / styles.css / app.js）

## 5. データモデル（概要）

### Progression（コード進行）

```ts
type Progression = {
  id: string
  title: string
  key: string           // e.g. "C", "Am"
  scale: string         // e.g. "major", "minor", "blues"
  chords: string[]      // e.g. ["Am", "F", "C", "G"]
  memo: string
  createdAt: Date
  updatedAt: Date
}
```

### Phrase（フレーズ）

```ts
type Phrase = {
  id: string
  title: string
  key: string
  scale: string
  notes: string[]       // 音名リスト or TAB的な表現
  memo: string
  createdAt: Date
}
```

## 6. 技術スタック（候補）

| レイヤー | 候補 | 理由 |
|--------|------|------|
| フレームワーク | Next.js (App Router) | SSG + SEO + 共有 URL 生成に強い |
| 言語 | TypeScript | 型安全な音楽理論ロジック |
| スタイリング | Tailwind CSS | 高速 UI 構築 |
| 音楽理論ライブラリ | Tonal.js | スケール・コード・キー判別 API が充実 |
| 指板描画 | SVG (カスタム実装) | コンパクトフレット表示に最適化しやすい |
| データ永続化 Phase 1 | localStorage | ログイン不要・即時利用可能 |
| データ永続化 Phase 2+ | 自作 Java API (Spring Boot) + PostgreSQL | 自作バックエンドでクラウド保存（ポートフォリオ目的） |
| 認証 Phase 2+ | 自作 Java API（JWT / httpOnly Cookie） | Cookie 認証 + CSRF 対策。localStorage データを移行・紐付け |
| ホスティング | Vercel | Next.js 最適化済み |

## 7. 優先度・開発フェーズ

### Phase 1（MVP）— コア体験を最速で確認

- [ ] キー・スケール選択 UI

- [ ] コード進行の入力・保存（localStorage）

## 9. 用語定義

| 用語 | 定義 |
|------|------|
| キー（調） | 楽曲の中心となる音・スケール（例: Cメジャー、Aマイナー） |
| スケール | ある規則で並べた音の集合（例: メジャースケール、ペンタトニックスケール） |
| ブルーノート | ブルーススケール特有の音（マイナーペンタトニックの ♭5）|
| 構成音 | あるコードやスケールを構成する個々の音 |
| ダイアトニックコード | あるキーのスケール上にのみ存在する音で構成されたコード群 |
| コード進行 | 複数のコードを時系列に並べたもの |
| フレーズ | 短いメロディーやリフなど、印象的な音のまとまり |
| 指板 | ギターのネック上のフレット付き弦の領域 |
| localStorage | ブラウザに内蔵されたキーバリュー型のローカルストレージ |
